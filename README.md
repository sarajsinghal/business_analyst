### Healthcare Analytics — Python

[Open project files](https://github.com/sarajsinghal/business_analyst/tree/Business-Analyst/Health%20Care%20Analysis%20Using%20Python)

[Open project files](https://github.com/sarajsinghal/business_analyst/tree/Business-Analyst/Netflix%20Original%20Analysis%20using%20SQL)
